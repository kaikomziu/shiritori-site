# しりとりオンライン

ブラウザで遊べるリアルタイム・マルチプレイしりとりゲーム。
Node.js + Express + Socket.io。

## ローカルで動かす

```bash
npm install
npm start
```

`http://localhost:3000` を開く。複数タブ/複数端末で開けばそのまま対戦できます。

## 遊び方

1. ニックネームを入力して「部屋を作成」(または部屋コードを入力して「参加する」)
2. 全員揃ったらホストが「ゲーム開始」
3. 自分の番になったら、しりとりのルールに沿った単語をひらがな(カタカナ入力もOK、自動でひらがなに変換)で入力
4. 「ん」で終わる単語を言う/制限時間内に入力できないと脱落
5. 最後の1人が残ったら勝利

- 漢字・英数字は使えません(ひらがな/カタカナのみ)
- 一度使った単語はそのゲーム内では再使用不可
- 辞書(`data/words.txt`)に載っている単語のみ使用可能

## 単語リストの追加方法

`data/words.txt` を開いて、1行に1単語(ひらがな)を追加するだけです。
`#` で始まる行はコメントとして無視されます。サーバーを再起動すると反映されます。

```
# 例
めろん
りんご
```

## ネット公開(Render)

このリポジトリを GitHub に push し、Render で「New Web Service」からこのリポジトリを
選択するだけでデプロイできます(`render.yaml` 同梱、ビルド: `npm install` / 起動: `npm start`)。
無料プランの場合、一定時間アクセスがないとスリープし、次のアクセス時に起動まで
数十秒かかることがあります。
