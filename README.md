# しりとりオンライン

ブラウザで遊べるリアルタイム・マルチプレイしりとりゲーム。
Node.js + Express + Socket.io。

## ローカルで動かす

```bash
npm install
npm start
```

`http://localhost:3000` を開く。複数タブ/複数端末で開けばそのまま対戦できます。

## 遊び方

1. ニックネームを入力して「部屋を作成」(または部屋コードを入力して「参加する」)
2. 全員揃ったらホストが「ゲーム開始」
3. 自分の番になったら、しりとりのルールに沿った単語をひらがな(カタカナ入力もOK、自動でひらがなに変換)で入力
4. 「ん」で終わる単語を言う/制限時間内に入力できないと脱落
5. 最後の1人が残ったら勝利

- 漢字・英数字は使えません(ひらがな/カタカナのみ)
- 一度使った単語はそのゲーム内では再使用不可
- 辞書(`data/words.txt`)に載っている単語のみ使用可能

## しりとりのルール(くわしく・つながり判定)

判定ロジックは [server.js](server.js) の `effectiveFirstChar` / `effectiveLastChar` に実装されています。

### 基本ルール

次に出す単語の**最初の文字**は、前の単語の**最後の文字**と同じでなければなりません。

例: 「りんご」→「ごりら」→「らっぱ」

### 小さい文字(拗音・促音・小さい母音)の扱い

語頭・語末が小さい文字の場合、対応する大きい文字として扱います。

| 小さい文字 | 大きい文字として扱う |
|---|---|
| ゃ | や |
| ゅ | ゆ |
| ょ | よ |
| ぁぃぅぇぉ | あいうえお |
| っ | つ |

例: 「きゃべつ」で終わったら次は「や」から始まる単語でOK(「ゃ」→「や」)。
逆に「や」で終わる単語の次に「ゃ」から始まる単語(があれば)も同様につながります。

### 長音符「ー」で終わる単語(例: コンティニュー、パソコンなど)

**語末が「ー」の場合は、その直前の文字の「母音(あ/い/う/え/お)」を実質的な最後の文字として扱います。**
次の単語は、その母音の文字(あ・い・う・え・お のいずれか)から始まる必要があります。

判定手順:
1. 単語の末尾が「ー」かどうかを見る
2. 「ー」なら、その手前の文字(小さい文字は上表で大きい文字に変換してから)の母音を調べる
3. 出てきた母音(あ/い/う/え/お)が、次の単語に求められる最初の文字になる

具体例:
- 「こんてぃにゅー」→ 末尾は「ー」→ 直前は「ゅ」→ 大きくすると「ゆ」→ 母音は「う」→ 次は **「う」から始まる単語**(例: うさぎ)
- 「けーき」→ 「ー」は語末ではなく途中なのでこのルールは関係なし。ふつうに末尾「き」から始まる単語につながる
- 「たおる」→ 「ー」を含まないのでふつうに末尾「る」
- 「ぱそこん」のように「ー」を含まず「ん」で終わる → 下記の「ん」ルールへ
- 「すかーと」→ 末尾は「と」なのでこのルールは関係なし(「ー」は語末にないため)

母音の求め方の対応表(抜粋):

| 直前の文字(大文字化後) | 母音 |
|---|---|
| か・さ・た・な・は・ま・や・ら・わ の段(あ段) | あ |
| き・し・ち・に・ひ・み・り の段(い段) | い |
| く・す・つ・ぬ・ふ・む・ゆ・る の段(う段) | う |
| け・せ・て・ね・へ・め・れ の段(え段) | え |
| こ・そ・と・の・ほ・も・よ・ろ・を の段(お段) | お |

濁音(が・ざ・だ・ば行)、半濁音(ぱ行)も同じ段の母音になります(例: 「ご」の母音は「お」)。

「ー」が連続している場合(例: 「まぁー」のような表記)は、「ー」以外の文字が出てくるまでさかのぼって母音を調べます。

### 「ん」で終わる単語

単語の**実際の最後の文字**(「ー」変換前の文字そのもの)が「ん」の場合、しりとりの伝統ルールどおり、その単語を出したプレイヤーはその時点で脱落します(単語自体は正しい手として履歴には残ります)。

### そのほかの判定

- 前の単語と同じ単語、すでにこのゲーム内で使われた単語は使えません(重複不可)
- 辞書(`data/words.txt`)に載っていない単語は使えません
- 漢字・英数字は入力エラーになります(カタカナは自動でひらがなに変換されます)

## 辞書データの出典

`data/words.txt` は以下のデータを組み合わせています。

- 手動で追加した一般的な単語・固有名詞(動物/食べ物/地名/ゲームタイトルなど)
- [elzup/jlpt-word-list](https://github.com/elzup/jlpt-word-list)(MITライセンス)由来の
  JLPT N1〜N5相当語彙の読み仮名
- [scriptin/jmdict-simplified](https://github.com/scriptin/jmdict-simplified)(JMdict、
  EDRDGライセンス)の「common(よく使われる語)」に分類された語の読み仮名

いずれも読み仮名(単語そのもの)のみを抽出して取り込んでおり、各データセットの語釈・用例などは
含んでいません。

## 単語リストの追加方法

`data/words.txt` を開いて、1行に1単語(ひらがな)を追加するだけです。
`#` で始まる行はコメントとして無視されます。サーバーを再起動すると反映されます。

```
# 例
めろん
りんご
```

## ネット公開(Render)

このリポジトリを GitHub に push し、Render で「New Web Service」からこのリポジトリを
選択するだけでデプロイできます(`render.yaml` 同梱、ビルド: `npm install` / 起動: `npm start`)。
無料プランの場合、一定時間アクセスがないとスリープし、次のアクセス時に起動まで
数十秒かかることがあります。
